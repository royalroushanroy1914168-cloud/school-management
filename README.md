# ABC Public School Website

This is the actual website source code, not an instruction document.

## Run locally
1. Install Node.js.
2. Run `npm install`.
3. Set `DATABASE_URL`.
4. Run `npm start`.
5. Open http://localhost:10000

## Render
Root Directory: .
Build Command: npm install
Start Command: npm start
